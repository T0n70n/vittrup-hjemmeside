# Vittrup Udendørsservice

Hjemmeside for Vittrup Udendørsservice i Brande. Statisk side (HTML, CSS og billeder), hostet på Cloudflare Pages.

- `index.html` – hele siden
- `img/` – logo og billeder
- `_headers` – cache-indstillinger til Cloudflare Pages

Cloudflare Pages: ingen build-kommando, output-mappe er roden.
